Building an Enterprise Network Security Monitoring Lab with Proxmox, Arkime, Suricata, Zeek, and SiLK

Posted on June 30, 2026

Following completion of the SANS GCIA (GIAC Certified Intrusion Analyst) certification, I designed and built an enterprise-style Network Security Monitoring (NSM) platform to better understand how packet capture, intrusion detection, protocol analysis, and network flow analytics work together during real-world investigations.

Rather than deploying an all-in-one appliance, I assembled the monitoring pipeline myself using Proxmox, Open vSwitch, Arkime, Suricata, Zeek, SiLK, and YAF. The project documents the complete telemetry pipeline—from mirrored network traffic and full packet capture to IDS alerts, protocol metadata, and searchable flow records—while also describing the troubleshooting required to validate each stage.

The completed lab now serves as the foundation for future projects involving malware analysis, threat hunting, detection engineering, and incident response investigations.
